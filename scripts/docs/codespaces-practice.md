## Understanding Git Workflow
Explain in 2–3 sentences the difference between:
- Local workspace (Codespace)
- Remote repository (GitHub.com)
The codespace is the local working copy where files are edited and snapshots can be saved via commits. The GitHub.com repository is the public copy that only reflects the changes made in the codespace once they have been synced.
